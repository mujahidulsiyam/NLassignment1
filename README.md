# TypeScript & OOP Problem Solving Assignment

## Overview
This repository contains my solutions for the Assignment: Problem Solving with TypeScript & OOP. The project demonstrates core TypeScript concepts, including basic types, optional parameters, readonly tuples, type narrowing, generics, Promises, and Object-Oriented Programming (OOP) principles. 

All coding solutions for the 8 problems are implemented in a single `solutions.ts` file.
